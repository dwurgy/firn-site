Support

Is Firn free?

Yes. It's also open source, so anyone can read the code.

What does it run on?

A Mac with macOS 14 or later.

Does Firn track me?

No. There's no telemetry, no account, and no analytics. The few things Firn does send are listed on the Privacy page.

Can I use extensions?

Not yet. I'm working toward it.

Is there a Windows version?

No. The old Windows app still opens, but it gets no updates or security fixes, so please move to an updated browser.
